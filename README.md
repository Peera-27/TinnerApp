# TinnerApp

แอปพลิเคชันเว็บที่พัฒนาด้วย **TypeScript**, **SCSS**, และ **HTML**  
ออกแบบมาเพื่อให้โค้ดมีโครงสร้างชัดเจน ดูแลง่าย และต่อยอดได้สะดวก

---

## 🚀 Features

- เขียน Logic ด้วย TypeScript เพื่อความปลอดภัยของชนิดข้อมูล (Type Safety)
- จัดการสไตล์ด้วย SCSS รองรับการแยกโมดูลและนำกลับมาใช้ซ้ำ
- โครงสร้างหน้าเว็บด้วย HTML ที่เรียบง่ายและปรับแต่งต่อได้ง่าย
- เหมาะสำหรับพัฒนาเป็น Web App ขนาดเล็กถึงกลาง

---

## 🧱 Tech Stack

- **TypeScript** (59.9%)
- **SCSS** (22.3%)
- **HTML** (17.8%)

## ⚙️ Getting Started

### 1) Clone repository

```bash
git clone https://github.com/Peera-27/TinnerApp.git
cd TinnerApp
```

### 2) Install dependencies

```bash
npm install
```

### 3) Run in development mode

```bash
npm run dev
```

### 4) Build for production

```bash
npm run build
```

### 5) Preview production build

```bash
npm run preview
```

> หากบางคำสั่งยังไม่มีใน `package.json` สามารถเพิ่ม script ให้ตรงกับเครื่องมือที่ใช้งาน (เช่น Vite / Webpack / Parcel)
